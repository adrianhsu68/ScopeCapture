示波器截圖 ScopeCapture — Windows 10/11 x64

免安裝：將 ScopeCapture.exe 複製到電腦，直接雙擊開啟。
不需要另外安裝 Python、VISA 或 Keysight IO Libraries。

第一次使用
1. 將電腦與示波器接到同一個可互通的區域網路，並開啟示波器。
2. 開啟 ScopeCapture.exe，確認搜尋網段，按「搜尋示波器」。
   右上角可切換「繁體中文 / English」，下次開啟會記住語言。
   通常可用自動帶出的 /24 網段；多張網卡可從下拉選單挑選。
   例如電腦 IP 是 192.168.1.50，搜尋網段可填 192.168.1.0/24。
3. 從清單點選正確的型號與序號。公司有多台相同型號時，請用序號辨識。
4. 選擇儲存資料夾與截圖背景（黑底／白底），按「擷取截圖」。圖片會自動命名並存為彩色 PNG。
   預設會自動開啟圖片，也可以取消勾選。

下次使用
程式會記住語言、上次選擇的儀器、IP、搜尋網段、儲存資料夾、截圖背景及自動開圖選項。
直接按「擷取截圖」即可。每次擷取都會重新確認型號和序號。
若 DHCP 更換 IP，重新搜尋並選擇該台儀器即可。
設定保存在目前 Windows 使用者的 %LOCALAPPDATA%\ScopeCapture\settings.json。
切換語言不會更改已選擇的資料夾。首次安裝預設存到 Pictures\ScopeCaptures。
首次使用依系統語言選擇介面；既有設定未記錄語言時保留繁體中文。
程式內的提示與錯誤會跟隨介面語言；Windows 原生檔案選擇視窗跟隨系統語言。

支援型號
Keysight EDUX1052A、EDUX1052G、DSOX1202A、DSOX1202G、DSOX1204A、DSOX1204G。
DSOX1204A 已實機驗證搜尋、截圖、黑白背景與省墨設定還原；EDUX1052A 經使用者實機確認可用。其餘型號尚待實機驗證。
依 Keysight 官方共用程式設計手冊實作，命令為 :DISPlay:DATA? PNG, COLor。
其他型號可能出現在搜尋清單中，但目前不開放截圖。
不提供 USB 連線，使用 IPv4 網路與 TCP 5025。

找不到儀器時
- 確認儀器已接上網路，在儀器的 Utility / I/O / LAN 設定查看 IP。
- 在程式直接輸入 IP，按「辨識並選取」；不同網段需能路由連通。
- 自動建議的網段使用 /24；實際網路若不同，請修改搜尋網段（最多 /22）。
- 搜尋不是跨網段自動探索；防火牆或 VLAN 隔離也可能阻擋 TCP 5025。
- 記住的儀器不代表目前在線；連線結果以按下截圖或手動辨識時為準。

截圖讀取當下顯示畫面，不會執行 Run/Stop、Autoscale 或修改量測設定。
預設黑底（螢幕原貌），也可選白底（適合列印）。
程式會暫時調整 Ink Saver 省墨設定，截圖後還原原值並確認。
若連線中斷或回覆不完整，會停止傳送指令並提示可能無法還原，請在儀器面板確認。
若需要固定某個瞬間，可先在示波器面板按 Stop，再到電腦截圖。
圖片名稱包含日期時間、型號、序號，避免多台儀器的圖片混淆。

此程式未經數位簽章，Windows 或公司防毒軟體可能提示發行者未知。
若公司政策阻擋，請交由資訊人員核准，不要關閉防護功能。
